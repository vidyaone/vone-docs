vSoftware-EnquiryAPI — Developer Guide

Postman setup

  1. Use Postman for web (web.postman.co), not the desktop app.
  2. Install the Postman Interceptor Chrome extension — it lets Postman's web app read cookies from your Chrome session.
  3. Enable Interceptor, then log into the product normally in Chrome. Once logged in, your session is available to Postman automatically — you don't need to set any auth header or cookie by hand.
  4. Download the collection from the navbar link above and import it into Postman, then send requests — it's pre-configured for Testing.

Common rules

Headers

  • Content-Type: application/json on every request that sends a body (POST/PUT).
  • Idempotency-Key: caller-generated UUID, required on every POST/PUT/DELETE. See each route below for what repeating the same request actually does.
  • Authentication required on every route below.

Shared query parameter

Every single route also requires:

ParamTypeRequiredNotes
productstringrequiredProduct/subdomain identifier.

Response envelope

Every response — success or failure — has this shape:

{
  "success": boolean,
  "message": string | null,
  "data": object | null,
  "errors": [ { "code": string, "message": string, "field": string | null } ] | null
}

Success example:

{
  "success": true,
  "message": "Success.",
  "data": 101,
  "errors": null
}

Error example:

{
  "success": false,
  "message": "Validation failed.",
  "data": null,
  "errors": [
    { "code": "VALIDATION_FAILED", "message": "StatusName is required.", "field": "PostDTO.StatusName" }
  ]
}

Switch on errors[].code — never on the message text.

Status codes and error codes

StatusCodeWhen
200—Request succeeded.
400VALIDATION_FAILEDA request field failed validation (missing, too long, out of range).
400REQUIRED_FIELDproduct query parameter is missing.
401UNAUTHORIZEDAuthentication cookie missing or invalid.
404RECORD_NOT_FOUNDThe record doesn't exist, doesn't belong to your institute, is already in that state, or was changed by another request first.
409DUPLICATE_RECORDA record with that name already exists for your institute.
500INTERNAL_ERRORUnexpected server error.

Status

POST /enquiry/setting/status

Creates an enquiry status for your institute.

Request

EnvironmentURL
Testinghttps://api-vsof.vidyaone.com/test/enquiry/setting/status?product=scl-software

Headers: Content-Type: application/json, Idempotency-Key: <uuid>

Sample request

POST /enquiry/setting/status?product=scl-software
{
  "statusName": "Open"  // required, string, max 100 chars
}

Response

200

{ "success": true, "message": "Success.", "data": 101, "errors": null }

data is the new status's id.

StatusCodeCondition
400VALIDATION_FAILEDstatusName missing or over 100 characters.
409DUPLICATE_RECORDA status with this name (case-insensitive) already exists for your institute.

Repeating the same request body returns 409 DUPLICATE_RECORD once the first call has created the status — the name now already exists.

PUT /enquiry/setting/status

Updates an enquiry status's name.

Request

EnvironmentURL
Testinghttps://api-vsof.vidyaone.com/test/enquiry/setting/status?product=scl-software

Headers: Content-Type: application/json, Idempotency-Key: <uuid>

Sample request

PUT /enquiry/setting/status?product=scl-software
{
  "statusId": 101,        // required, integer, > 0
  "statusName": "Closed"  // required, string, max 100 chars
}

Response

200

{ "success": true, "message": "Status updated successfully.", "data": null, "errors": null }
StatusCodeCondition
400VALIDATION_FAILEDstatusId missing/not > 0, or statusName missing/over 100 characters.
404RECORD_NOT_FOUNDNot found for your institute, already deleted, already deactivated, or changed by another request first.
409DUPLICATE_RECORDAnother status already has this name for your institute.

Repeating the same request body returns 200 again — updating to the same, unchanged name is not blocked.

GET /enquiry/setting/status/list

Lists enquiry statuses for your institute, plus any shared (common) statuses, optionally filtered. Deleted statuses are never included. Results are ordered by name.

Request

EnvironmentURL
Testinghttps://api-vsof.vidyaone.com/test/enquiry/setting/status/list

Sample request

GET /enquiry/setting/status/list?product=scl-software
    &isActive=true    // optional, boolean — filter by active state; omit for both
    &name=Open        // optional, string — case-insensitive "contains" match on statusName; omit for all
    &pageNumber=1      // optional, integer, default 1
    &pageSize=10       // optional, integer, default 10, max 200

Response

200

{
  "success": true,
  "message": null,
  "data": {
    "records": [
      { "statusId": 101, "statusName": "Open", "isCommon": false, "enquiryCount": 5, "isActive": true }
    ],
    "metaData": {
      "totalCount": 1,
      "pageSize": 10,
      "currentPage": 1,
      "totalPages": 1,
      "hasNext": false,
      "hasPrevious": false
    }
  },
  "errors": null
}
StatusCodeCondition
400VALIDATION_FAILEDpageNumber not > 0, or pageSize not > 0 or over 200.
