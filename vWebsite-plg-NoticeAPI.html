vWebsite-plg-NoticeAPI — Developer Guide

Documents the Notice resource.

Postman setup guide

  1. Use Postman for web (web.postman.co), not the desktop app.
  2. Install the Postman Interceptor Chrome extension — it lets Postman's web app read cookies from your Chrome session.
  3. Enable Interceptor, then log into the product normally in Chrome. Once logged in, your session is available to Postman automatically — you don't need to set any auth header or cookie by hand.
  4. Download the collection from the link in the navbar above and import it into Postman, then send requests — it's pre-configured for Testing.

Common request & response rules

Authentication

Authentication required on every route documented in this guide.

Headers required on every request

HeaderRequiredNotes
Content-Type: application/jsonwrites onlyRequired on any request that carries a body.
Idempotency-Keymutating requestsA UUID the caller generates per request. Required on every POST / PUT / DELETE below. See the Idempotency line under each endpoint for what happens if you resend the same key/body.

Common query parameter

NameTypeRequiredNotes
productstringyesCalling client-app identifier, e.g. scl-website. Required on every route below.

Response envelope

Every response — success or failure — uses the same JSON shape:

{
  "success": true | false,
  "message": "human-readable string" | null,
  "errors":  [ { "code": "...", "message": "...", "field": "..." } ] | null,
  "data":    { ... } | [ ... ] | true | false | null
}

Success example:

{ "success": true, "message": null, "errors": null, "data": { "noticeId": 501, "imagePresign": null } }

Error example:

{
  "success": false,
  "message": "Validation failed.",
  "errors": [ { "code": "VALIDATION_FAILED", "message": "title is required and must be at most 200 characters.", "field": "Notice.Title" } ],
  "data": null
}

Each entry in errors[] has a machine-readable code — switch on code, not on message text.

JSON bodies accept numeric ids and numbers sent either as numbers or as quoted strings ("noticeId": 501 and "noticeId": "501" are equivalent).

POST /notice

Creates a new notice for the calling institution.

Request

EnvironmentURL
TestingPOST https://api-vweb.vidyaone.com/test/plugin/notice/notice?product={product}
ProductionPOST https://api-vweb.vidyaone.com/plugin/notice/notice?product={product}

Sample request body

{
  "title": "Annual Sports Day",                                             // required, string, max 200 chars
  "description": "Join us for the annual sports day on the school grounds.", // required, string
  "imageFileName": "sports-day.jpg",                                        // optional, string, max 255 chars — requesting an image upload slot; see "Uploading the image" below
  "publishDate": "2026-11-01",                                              // required, string, date (yyyy-MM-dd)
  "expiryDate": "2026-11-15",                                               // optional, string, date (yyyy-MM-dd) — must be on or after publishDate
  "noticeStatus": true                                                      // optional, boolean, default true
}

Uploading the image

Sending imageFileName returns a presigned S3 upload in the response, resolved before the notice is created — an unsupported or unsafe file name fails the whole request with 400 INVALID_INPUT and no notice is created. On success, the notice's imageSrc is already set to the final URL (shown as data.imagePresign.publicUrl below) — no second call is needed to record it. POST the raw file bytes plus every field in data.imagePresign.post.fields directly to data.imagePresign.post.url (as multipart form fields, file field last) within expiresIn seconds.

Allowed extensions (case-insensitive)Max size
jpg, jpeg, png, gif, webp, bmp10 MB (10485760 bytes)

Also rejected regardless of extension: a name over 200 characters, one containing a path separator (/ or \), .., a control character, or a second, disguised extension (e.g. invoice.php.jpg).

Response

200 OK

{
  "success": true,
  "message": null,
  "errors": null,
  "data": {
    "noticeId": 501,
    "imagePresign": {
      "key": "vWebsite/plugin_cdn/notice/inst_321/3f2a1b4c5d6e7f8091a2b3c4d5e6f708.jpg",
      "publicUrl": "https://vidyaone-data-lake.s3.ap-south-1.amazonaws.com/vWebsite/plugin_cdn/notice/inst_321/3f2a1b4c5d6e7f8091a2b3c4d5e6f708.jpg",
      "post": {
        "url": "https://vidyaone-data-lake.s3.ap-south-1.amazonaws.com/",
        "fields": {
          "key": "vWebsite/plugin_cdn/notice/inst_321/3f2a1b4c5d6e7f8091a2b3c4d5e6f708.jpg",
          "x-amz-server-side-encryption": "AES256",
          "x-amz-credential": "ASIAEXAMPLE/20261012/ap-south-1/s3/aws4_request",
          "x-amz-algorithm": "AWS4-HMAC-SHA256",
          "x-amz-date": "20261012T000000Z",
          "policy": "eyJleHBpcmF0aW9uIjoiMjAyNi0xMC0xMlQwMDowMjowMFoi...",
          "x-amz-signature": "a1b2c3d4e5f6..."
        }
      },
      "expiresIn": 120,
      "maxFileSize": 10485760,
      "contentTypePrefix": "image/"
    }
  }
}

imagePresign is null unless imageFileName was sent.

StatuscodeFires when
400VALIDATION_FAILEDA field constraint above fails, or the body is missing / invalid.
400REQUIRED_FIELDproduct missing.
401UNAUTHORIZEDAuthentication required.
400INVALID_INPUTimageFileName has an unsupported or unsafe value (see "Uploading the image" above) — the notice is not created.

Idempotency. Sending the same Idempotency-Key and body again creates a second, separate notice — no duplicate detection is performed.

PUT /notice

Updates a notice belonging to the calling institution. Every writable field is overwritten with the value sent — there is no partial update.

Request

EnvironmentURL
TestingPUT https://api-vweb.vidyaone.com/test/plugin/notice/notice?product={product}
ProductionPUT https://api-vweb.vidyaone.com/plugin/notice/notice?product={product}

Same fields as Create notice, plus noticeId. Omitting imageFileName leaves the notice's current image untouched; sending it replaces the image the same way as create.

Sample request body

{
  "noticeId": 501,                                                          // required, integer, > 0 — must belong to the caller's institution
  "title": "Annual Sports Day (Updated)",                                    // required, string, max 200 chars
  "description": "Join us for the annual sports day — now with a new venue.", // required, string
  "imageFileName": "sports-day-v2.jpg",                                     // optional, string, max 255 chars — see "Uploading the image" below; omit to leave the current image untouched
  "publishDate": "2026-11-01",                                              // required, string, date (yyyy-MM-dd)
  "expiryDate": "2026-11-20",                                               // optional, string, date (yyyy-MM-dd) — must be on or after publishDate
  "noticeStatus": true                                                      // optional, boolean, default true
}

Uploading the image

Sending imageFileName returns a presigned S3 upload in the response, resolved before the update is written — an unsupported or unsafe file name fails the whole request with 400 INVALID_INPUT and nothing is updated. On success, the notice's imageSrc is already set to the new final URL. POST the raw file bytes plus every field in data.imagePresign.post.fields directly to data.imagePresign.post.url (as multipart form fields, file field last) within expiresIn seconds.

Allowed extensions (case-insensitive)Max size
jpg, jpeg, png, gif, webp, bmp10 MB (10485760 bytes)

Also rejected regardless of extension: a name over 200 characters, one containing a path separator (/ or \), .., a control character, or a second, disguised extension (e.g. invoice.php.jpg).

Response

200 OK

{
  "success": true,
  "message": null,
  "errors": null,
  "data": {
    "updated": true,
    "imagePresign": {
      "key": "vWebsite/plugin_cdn/notice/inst_321/9c8b7a6d5e4f3021.jpg",
      "publicUrl": "https://vidyaone-data-lake.s3.ap-south-1.amazonaws.com/vWebsite/plugin_cdn/notice/inst_321/9c8b7a6d5e4f3021.jpg",
      "post": { "url": "https://vidyaone-data-lake.s3.ap-south-1.amazonaws.com/", "fields": { "...": "..." } },
      "expiresIn": 120,
      "maxFileSize": 10485760,
      "contentTypePrefix": "image/"
    }
  }
}

imagePresign is null unless imageFileName was sent.

StatuscodeFires when
400VALIDATION_FAILEDA field constraint fails, noticeId missing or not > 0, or the body is missing / invalid.
400REQUIRED_FIELDproduct missing.
401UNAUTHORIZEDAuthentication required.
404RECORD_NOT_FOUNDNo matching notice for this institution.
400INVALID_INPUTimageFileName has an unsupported or unsafe value (see "Uploading the image" above) — nothing is updated.

Idempotency. Sending the same Idempotency-Key and body again returns 200 OK and leaves the notice in the same final state.
