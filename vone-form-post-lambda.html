vone-form-post-lambda

Request payload format for the form-ingest Lambda (region: ap-south-1). Share this with frontend/integration developers.

Endpoint POST

Preflight OPTIONS requests are handled automatically (204, no body).

Required headers

Content-Type: application/json
Origin: https://vidyaone.com          (or any *.vidyaone.com subdomain — https only)
User-Agent: <browser UA>              (missing counts as a bot signal)
Referer: <page the form was submitted from>  (missing counts as a bot signal)

Note: a submission is rejected as bot/spam once 2 or more bot signals fire (missing User-Agent, known bot User-Agent, missing Referer).

Example request body

{
  "form_type": "contact",
  "subject": "New enquiry",
  "form_fields": {
    "name": "Jane Doe",
    "email": "jane@example.com",
    "message": "I'd like to book a demo."
  },
  "page": {
    "url": "https://vidyaone.com/contact"
  }
}

Field reference

FieldRequiredRules
form_type Required String. Must be one of the allowed form types (see below). Case-insensitive.
subject Optional String, ≤ 5000 chars, restricted character set (see below).
form_fields Required JSON object with at least one non-blank value. Keys must be strings ≤ 100 chars.
form_fields.<key> — String values ≤ 5000 chars, restricted character set, must not contain .. or \.
form_fields.email If key present Must match local@domain shape (e.g. name@example.com).
page.url Required Valid http(s):// URL whose host is vidyaone.com or a subdomain.

Allowed form_type values

contact feedback talk_to_an_expert branding_consultation setup_implementation customization_callback advance_technical_callback callback callback_vss callback_scl_website callback_pre_website complaint complaint_vss complaint_scl_website complaint_pre_website lead lead_vss lead_scl_website lead_pre_website demo_scl_website demo_vss demo_pre_website trial_vss onboarding_vss onboarding_scl_website onboarding_pre_website domain_booking_scl_website activate_ssl_scl_website domain_booking_pre_website activate_ssl_pre_website success_story

Character set & size limits

Applies to subject, form_type, and string values in form_fields:

Allowed: letters, digits, whitespace, and  @ . - , ! ? : ( ) [ ] /
Max total payload size1,000,000 bytes
Max chars per form_fields value / subject5,000
Max chars per form_fields key100
