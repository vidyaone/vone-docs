vShared-DataAPI — Developer Guide

Documents the Options and Product resources — shared lookup/reference data and product/plan option data used across VIDYAOne products.

Postman setup guide

  1. Use Postman for web (web.postman.co), not the desktop app.
  2. Install the Postman Interceptor Chrome extension — it lets Postman's web app read cookies from your Chrome session.
  3. Enable Interceptor, then log into the product normally in Chrome. Once logged in, your session is available to Postman automatically — you don't need to set any auth header or cookie by hand.
  4. Download the collection from the link in the navbar above and import it into Postman, then send requests — it's pre-configured for Testing.

Base URLs

Testinghttps://api-shared.vidyaone.com/test/data/

Concatenate the base URL with the route shown in each endpoint below. There is no version segment.

Common request & response rules

Authentication

Authentication required on every route documented in this guide.

Common query parameter

NameTypeRequiredNotes
productstringnoAccepted on every route below. Omitting it does not change the response.

Response envelope

Every response — success or failure — uses the same JSON shape:

{
  "success": true | false,
  "message": "human-readable string" | null,
  "errors":  [ { "code": "...", "message": "...", "field": "..." } ] | null,
  "data":    [ ... ] | null
}

Success example:

{
  "success": true,
  "message": null,
  "errors": null,
  "data": [
    { "id": 1, "name": "Male" },
    { "id": 2, "name": "Female" }
  ]
}

An empty result is still 200 OK with "data": [] — never a 404.

Error example:

{
  "success": false,
  "message": "Validation failed.",
  "errors": [ { "code": "VALIDATION_FAILED", "message": "State ID must be greater than 0.", "field": "CountryId" } ],
  "data": null
}

Each entry in errors[] has a machine-readable code — switch on code, not on message text.

Status & error codes used in this guide

StatuscodeFires when
200—Success. Also returned for an empty result ("data": []).
400VALIDATION_FAILEDA required id query parameter (categoryId, countryId, stateId, productId) is missing, not a number, or ≤ 0.
401UNAUTHORIZEDAuthentication cookie missing or invalid.
500INTERNAL_ERRORUnexpected server error.

Options

Lookup/reference dropdown data. Every route below takes no request body and returns a flat list — either { id, name } pairs, or a wider shape where noted.
