Postman setup

  1. Use Postman for web (web.postman.co), not the desktop app.
  2. Install the Postman Interceptor Chrome extension — it lets Postman's web app read cookies from your Chrome session.
  3. Enable Interceptor, then log into the product normally in Chrome. Once logged in, your session is available to Postman automatically.
  4. Download the collection from the link in the navbar above and import it into Postman, then send requests — it's pre-configured for Testing.

These endpoints have no authentication requirement (see Common rules), so Interceptor/cookies aren't actually needed to call them — steps 2–3 are only relevant if you also use this same Postman workspace against authenticated vOne endpoints.

Common rules

Headers

HeaderRequirementRule
OriginoptionalOnly affects CORS response headers — echoed back as Access-Control-Allow-Origin when it's https://vidyaone.com or a subdomain, https only. Not a request gate.

No request headers are required. No authentication is required to call any of these endpoints.

Query parameters (shared)

Every route below requires at least one of guest_id / user_id. Missing both → 400.

Response envelope

Every response is { "success": boolean, "message": string, "errors": null, "data": ... }. errors is always null in practice — there is no separate error-code field; distinguish error cases by HTTP status and the message text.

// success (200) — shape of "data" varies by route, see each route below
{ "success": true, "message": "", "errors": null, "data": [ /* ... */ ] }

// error (400/404/409/500)
{ "success": false, "message": "Query parameter 'guest_id' must not be blank", "errors": null, "data": [] }

data on an error response is [] for GET /website/cart, and {} for GET /payment/payasguest and DELETE /website/cart (matching each route's own success shape).

Status overview

StatusWhen
204OPTIONS preflight — returned immediately, no body.
200Request validated and processed successfully.
400Missing/invalid guest_id, user_id or item_id — see the route below for exact messages.
404No matching data found (route-specific — see below).
405Method other than GET/DELETE/OPTIONS.
409DELETE only — the item is already paid.
500Unexpected error.

Cart

GET /website/cart

Returns the current (unpaid) cart items for a guest and/or logged-in user, newest first.

Request

URL (Testing): https://api.vidyaone.com/website/cart

ParamTypeRequiredConstraint
guest_idstringconditional1–100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
user_idintegerconditional> 0 — required if guest_id is omitted

Sample request

GET https://api.vidyaone.com/website/cart
    ?guest_id=guest_a1b2c3d4   // conditional, string, 1-100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
    &user_id=10234             // conditional, integer, > 0 — required if guest_id is omitted

GET /payment/payasguest

Returns a summarized pay-as-guest checkout total (only cart items marked payAsGuest) for a guest and/or logged-in user.

Request

URL (Testing): https://api.vidyaone.com/payment/payasguest

ParamTypeRequiredConstraint
guest_idstringconditional1–100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
user_idintegerconditional> 0 — required if guest_id is omitted

Sample request

GET https://api.vidyaone.com/payment/payasguest
    ?guest_id=guest_a1b2c3d4   // conditional, string, 1-100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
    &user_id=10234             // conditional, integer, > 0 — required if guest_id is omitted

Response

200

{
  "success": true,
  "message": "",
  "errors": null,
  "data": {
    "guestId": "guest_a1b2c3d4",
    "prodSummery": "1. School Website-Premium Support Starter Pack 4999.00",
    "totalAmt": 4999.0,
    "totalDis": 500.0,
    "netPayable": 4499.0
  }
}

prodSummery is a newline-separated list, one "<n>. <productName>-<planName> <itemName> <price>" line per matched item — it does not include serviceName, so a service-based item's line shows a blank product/plan segment.

400 — same messages as GET /website/cart above.

404 — "No pay-as-guest cart items found for this guest" — no matching items.

500 — "Internal server error".

DELETE /website/cart

Deletes one cart item by item_id, unless it has already been paid.

Request

URL (Testing): https://api.vidyaone.com/website/cart

ParamTypeRequiredConstraint
guest_idstringconditional1–100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
user_idintegerconditional> 0 — required if guest_id is omitted
item_idstringrequired1–100 chars, pattern ^[A-Za-z0-9_-]+$

Sample request

DELETE https://api.vidyaone.com/website/cart
    ?guest_id=guest_a1b2c3d4                          // conditional, string, 1-100 chars, pattern ^[A-Za-z0-9_-]+$ — required if user_id is omitted
    &user_id=10234                                    // conditional, integer, > 0 — required if guest_id is omitted
    &item_id=c4d1e2f3-9a8b-4c5d-8e7f-1a2b3c4d5e6f      // required, string, 1-100 chars, pattern ^[A-Za-z0-9_-]+$

Response

200

{
  "success": true,
  "message": "Item deleted",
  "errors": null,
  "data": { "itemId": "c4d1e2f3-9a8b-4c5d-8e7f-1a2b3c4d5e6f" }
}

400:

  • Same guest_id/user_id messages as GET /website/cart above.
  • "Query parameter 'item_id' is required"
  • "Query parameter 'item_id' must not be blank"
  • "Query parameter 'item_id' contains invalid characters"

404 — "Item not found".

409 — "Item has already been paid and cannot be deleted".

500 — "Internal server error".
