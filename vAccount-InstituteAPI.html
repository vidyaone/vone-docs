Common request & response rules

Authentication

Authentication required on every route documented in this guide.

Headers required on every request

HeaderRequiredNotes
Content-Type: application/jsonwrites onlyRequired on any request that carries a body.
Idempotency-Keymutating requestsA UUID the caller generates per request. Required on every POST / PUT / DELETE below. See the Idempotency line under each endpoint for what happens if you resend the same key/body.

Common query parameter

NameTypeRequiredNotes
productstringyesCalling product identifier, e.g. lms. Prefix with test- to run the request in test mode, e.g. test-lms. Required on every route below.

Response envelope

Every response — success or failure — uses the same JSON shape:

{
  "success": true | false,
  "message": "human-readable string" | null,
  "errors":  [ { "code": "...", "message": "...", "field": "..." } ] | null,
  "data":    { ... } | [ ... ] | null
}

Success example (command):

{ "success": true, "message": "Success.", "errors": null, "data": null }

Error example:

{
  "success": false,
  "message": "Validation failed.",
  "errors": [ { "code": "VALIDATION_FAILED", "message": "orgName is required.", "field": "postDTO.orgName" } ],
  "data": null
}

Each entry in errors[] has a machine-readable code — switch on code, not on message text.

Status & error codes used in this guide

StatuscodeFires when
200—Success.
400VALIDATION_FAILEDA request field fails validation, or the body is missing / not valid JSON.
400REQUIRED_FIELDproduct is missing from the query string.
400LIMIT_EXCEEDEDThe caller already created-or-owns 3 non-deleted organizations (POST /org only).
401UNAUTHORIZEDAuthentication failed.
404RECORD_NOT_FOUNDThe target organization doesn't match the request (missing, not owned by the caller, deleted, deactivated, or otherwise ineligible — see each endpoint).
409DUPLICATE_RECORDThe orgName or regNo sent is already in use by another organization.
409FOREIGN_KEY_VIOLATIONorgTypeId, districtId, stateId, or countryId doesn't reference an existing record.
500INTERNAL_ERRORUnexpected server error.

Postman setup guide

  1. Use Postman for web (web.postman.co), not the desktop app.
  2. Install the Postman Interceptor Chrome extension — it lets Postman's web app read cookies from your Chrome session.
  3. Enable Interceptor, then log into the product normally in Chrome. Once logged in, your session is available to Postman automatically — you don't need to set any auth header or cookie by hand.
  4. Import vAccount-InstituteAPI.postman_collection.json, select the matching environment/baseUrl variable, and send requests.

Organization

Most routes below act only on organizations the caller created or owns. Get organization is the one exception — any authenticated caller can read any organization, with the response shape depending on their relationship to it. A caller may create-or-own at most 3 non-deleted organizations.

POST /org

Creates a new organization for the caller.

Request

EnvironmentURL
TestingPOST https://api-vacc.vidyaone.com/test/inst/org?product={product}
ProductionPOST https://api-vacc.vidyaone.com/inst/org?product={product}

Body — nested under postDTO:

FieldTypeRequiredConstraints
orgNamestringyesMax 150 chars.
orgTypeIdintegeryes> 0; must reference an existing organization type.
mobilestringyesExactly 10 digits.
districtIdintegeryes> 0; must reference an existing record.
stateIdintegeryes> 0; must reference an existing record.
countryIdintegeryes> 0; must reference an existing record.
emailstringyesValid email, max 50 chars.
addressstringyesMax 500 chars.
pincodestringyesMax 10 chars.
regNostringnoMax 50 chars.
regDatestring (date-time)noISO-8601. Defaults to the current time if omitted.
logostringnoMax 100 chars.
isOwnerbooleannoDefault false. When false, ownerName and ownerEmail become required.
ownerNamestringconditionalRequired (max 150 chars) when isOwner=false.
ownerEmailstringconditionalRequired (valid email, max 150 chars) when isOwner=false.
isWhatsappNumberbooleannoDefault false.
isDefaultbooleannoDefault false. The caller's first organization is always created as their default, regardless of this value.
legalDocumentPathstringnoMax 255 chars.
legalDocumentTypestringnoMax 50 chars.
identityProofPathstringnoMax 255 chars.
identityProofTypestringnoMax 50 chars.
remarksstringnoMax 500 chars.
submittedAtstring (date-time)noISO-8601.

proceedWithKyc and kycStatus are not request fields. Sending both legalDocumentPath and identityProofPath results in kycStatus: "Under Review" in later reads; otherwise kycStatus: "Pending".

  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
        "postDTO": {
          "orgName": "Acme Institute",
          "orgTypeId": 1,
          "mobile": "9876543210",
          "email": "info@acme.example",
          "regNo": "REG-2024-0007",
          "address": "12 MG Road",
          "districtId": 501, "stateId": 27, "countryId": 91,
          "pincode": "560001",
          "logo": "org/acme/logo.png",
          "isOwner": true,
          "ownerName": "Asha Rao",
          "ownerEmail": "asha@acme.example",
          "isWhatsappNumber": true,
          "isDefault": true,
          "legalDocumentType": "GST",
          "legalDocumentPath": "org/acme/gst.pdf",
          "submittedAt": "2026-09-09T10:15:00Z"
        }
      }'

Response

{ "success": true, "message": "Success." }
StatuscodeFires when
400VALIDATION_FAILEDA field constraint above fails, or the body is missing / invalid.
400LIMIT_EXCEEDEDThe caller already created-or-owns 3 non-deleted organizations.
400REQUIRED_FIELDproduct missing.
401UNAUTHORIZEDAuthentication failed.
409DUPLICATE_RECORDorgName or regNo already in use.
409FOREIGN_KEY_VIOLATIONorgTypeId / districtId / stateId / countryId doesn't reference an existing record.

Idempotency. Sending the same Idempotency-Key and body again after a successful create returns 409 Conflict rather than the original success.

PUT /org

Updates an organization the caller created or owns, including its KYC data.

Request

EnvironmentURL
TestingPUT https://api-vacc.vidyaone.com/test/inst/org?product={product}
ProductionPUT https://api-vacc.vidyaone.com/inst/org?product={product}

Body — nested under putDTO, same fields as Create organization plus orgId. Every writable field is overwritten with the value sent — there is no partial update.

FieldTypeRequiredNotes
orgIdintegeryes> 0. Must be an organization the caller created or owns.
isOwner, ownerName, ownerEmail—conditionalOnce the organization has an accepted owner, values sent for these three fields are ignored and the existing owner is kept.
isDefaultbooleannotrue makes this the caller's default organization. Always honored as sent (no first-organization override, unlike Create organization).
All other fields — orgTypeId, mobile, regNo, regDate, email, address, districtId, stateId, countryId, pincode, logo, isWhatsappNumber, legalDocumentPath, legalDocumentType, identityProofPath, identityProofType, remarks, submittedAt — same type/requiredness/constraints as Create organization.

Sending legalDocumentPath / identityProofPath / legalDocumentType / identityProofType / remarks / submittedAt can change kycStatus, following this table (based on the organization's current kycStatus):

Current kycStatusConditionResulting kycStatus
Under ReviewanyRequest rejected — see error table below.
Approved / RejectedBoth documents removedPending
Approved / RejectedA document, or orgName/regNo/address, changedUnder Review
Approved / RejectedNothing above changedUnchanged
Pending / no KYC data yetBoth documents presentUnder Review
Pending / no KYC data yetNot both documents presentPending

Example request

curl -sS -X PUT "https://api-vacc.vidyaone.com/test/inst/org?product=lms" \
  --cookie "$SESSION_COOKIE" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  -d '{
        "putDTO": {
          "orgId": 123,
          "orgName": "Acme Institute (Renamed)",
          "orgTypeId": 1,
          "mobile": "9876543210",
          "email": "info@acme.example",
          "regNo": "REG-2024-0007",
          "address": "12 MG Road",
          "districtId": 501, "stateId": 27, "countryId": 91,
          "pincode": "560001",
          "logo": "org/acme/logo-v2.png",
          "isOwner": true,
          "ownerName": "Asha Rao",
          "ownerEmail": "asha@acme.example",
          "isWhatsappNumber": true,
          "isDefault": false,
          "legalDocumentPath": "org/acme/gst.pdf",
          "identityProofPath": "org/acme/pan.pdf",
          "remarks": "docs ok"
        }
      }'

Response

200 OK

{ "success": true, "message": "Organisation updated successfully." }
StatuscodeFires when
400VALIDATION_FAILEDA field constraint fails, orgId ≤ 0, or the body is missing / invalid.
400REQUIRED_FIELDproduct missing.
401UNAUTHORIZEDAuthentication failed.
404RECORD_NOT_FOUNDThe organization doesn't exist, isn't owned by the caller, is deleted, is deactivated, or its kycStatus is currently Under Review.
409DUPLICATE_RECORDorgName or regNo already in use.
409FOREIGN_KEY_VIOLATIONorgTypeId / districtId / stateId / countryId doesn't reference an existing record.

Idempotency. Sending the same Idempotency-Key and body again returns 200 OK and leaves the organization in the same final state.
